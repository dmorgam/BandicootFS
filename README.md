# BandicootFS

![BandicootFS](./assets/logo.png)

BandicootFS is a Go-based MCP server that turns your local filesystem into a
retrieval layer for AI models — no vector database required. It exposes files
and directories as MCP tools and resources, letting any MCP-compatible client
(Claude Desktop, IDE integrations, custom agents) search, read, and reason over
your data on demand. Lightweight, dependency-free, and runs locally.

> **Status: Work in Progress — Highly Incomplete**
>
> This project is in very early development. Most features described or implied
> are **not yet implemented**. Expect breaking changes, missing functionality,
> and unstable APIs.
